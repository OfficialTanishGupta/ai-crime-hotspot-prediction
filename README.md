# AI Crime Hotspot Prediction System

This project predicts crime-prone hotspots using historical crime data and machine learning techniques.

## Features
- Crime data preprocessing
- Hotspot prediction using ML
- REST API for predictions
- Future Android/Web integration

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Flask
- Folium
